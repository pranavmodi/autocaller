# Decisions — 2026-09-03

## D-2026-09-03-01 — Distinguish paused Lead Finder steps from failed attempts
- **Area:** infra
- **Status:** accepted
- **Decision:** Label a Lead Finder step `paused` when its provider request hits transient gateway pressure, while retaining the nested provider attempt's timed-out/failed status; also permit an explicit model-authored pause action when no useful work can proceed until a dependency recovers.
- **Why:** A red failed step incorrectly implies a terminal agent error, and reason-only automatic transitions can otherwise consume the run budget while merely restating an external verification block.
- **Refs:** app/services/lead_finder.py; app/services/lead_finder_provider.py; alembic/versions/o5p6q7r8s9t0_allow_paused_lead_finder_steps.py

## D-2026-09-03-02 — Give Possible OS a dedicated reusable Codex lane
- **Area:** infra
- **Status:** accepted
- **Decision:** Run a localhost-only Codex app-server as its own systemd service and expose a generic read-only Possible OS gateway; make Lead Finder the first consumer through a third run-wide `codex` provider.
- **Why:** This preserves Codex threads, tools, auth, streamed events, and usage while bypassing OpenClaw's Node event loop and shared lane. The generic API and CLI let future Possible OS agents reuse the service without Lead Finder coupling.
- **Refs:** deploy/systemd/possibleos-codex-app-server.service; app/services/codex_app_server.py; app/api/codex_gateway.py

## D-2026-09-03-03 — Repair malformed Codex transition payloads before tools run
- **Area:** lead-gen
- **Status:** superseded by D-2026-09-03-04
- **Decision:** Give completed Codex turns one bounded same-thread repair when a JSON-encoded dynamic field fails validation; persist both attempts, execute no tool before full validation, and pause resumably if repair is exhausted.
- **Why:** Strict outer schemas can prove that dynamic fields are strings but cannot prove that their contents are valid JSON. Treating a one-character model serialization error as a terminal run failure loses safe progress even though no side effect occurred.
- **Refs:** app/services/lead_finder_provider.py; app/services/lead_finder.py; tests/test_lead_finder.py

## D-2026-09-03-04 — Mechanically constrain the complete Codex transition
- **Area:** lead-gen
- **Status:** accepted
- **Decision:** Replace JSON-encoded dynamic fields with a versioned, fully typed, closed `outputSchema` covering state sections, candidate records, and the finite superset of available tool arguments; retain one repair only as defense in depth.
- **Why:** Outer structured output cannot validate JSON hidden inside a string. The Lead Finder state and tool set are finite, so mechanical validation is both feasible and cheaper than routinely repairing missing delimiters.
- **Refs:** app/services/lead_finder_provider.py; app/skills/lead-finder/SKILL.md; tests/test_lead_finder.py

## D-2026-09-03-05 — Queue shared OpenClaw work before the HTTP timeout
- **Area:** infra
- **Status:** accepted
- **Decision:** Serialize Possible OS calls into the shared `openclaw/main` lane inside the gateway client, before constructing the timed HTTP request.
- **Why:** Concurrent research workers were timing out while queued inside OpenClaw, while their abandoned server-side work continued and exhausted the gateway heap. A client-side single-flight gate keeps waiting cheap and ensures the configured timeout measures active gateway work rather than lane contention.
- **Refs:** app/services/llm_gateway.py
