# Decisions — 2026-09-03

## D-2026-09-03-01 — Distinguish paused Lead Finder steps from failed attempts
- **Area:** infra
- **Status:** accepted
- **Decision:** Label a Lead Finder step `paused` when its provider request hits transient gateway pressure, while retaining the nested provider attempt's timed-out/failed status; also permit an explicit model-authored pause action when no useful work can proceed until a dependency recovers.
- **Why:** A red failed step incorrectly implies a terminal agent error, and reason-only automatic transitions can otherwise consume the run budget while merely restating an external verification block.
- **Refs:** app/services/lead_finder.py; app/services/lead_finder_provider.py; alembic/versions/o5p6q7r8s9t0_allow_paused_lead_finder_steps.py
