# Decisions - 2026-08-26

## D-2026-08-26-01 - Own web research locally
- **Area:** data-arch
- **Status:** accepted
- **Decision:** EmailTag is no longer a web-research execution backend. Possible OS features that need web search must execute and persist that research locally; existing EmailTag research relays must be migrated before use.
- **Why:** EmailTag web search is disabled, while the Possible OS server has a loopback OpenClaw gateway and a local durable store.
- **Refs:** `PROJECT.md`, `CLAUDE.md`, `app/services/pif_job_posting_research.py`

## D-2026-08-26-02 - EmailTag ends at raw PIF extraction
- **Area:** data-arch
- **Status:** accepted
- **Decision:** EmailTag publishes a cursor-based raw extraction feed only. Possible OS preserves that source payload, owns canonical identity and all derived research, and queues changed firms into its durable local enrichment workers during daily delta sync.
- **Why:** One local owner prevents remote auth/research outages from breaking Leads and keeps derived state queryable without upstream calls.
- **Refs:** `app/services/firm_intel_sync.py`, `app/services/pif_local_enrichment.py`, `app/api/pif.py`
