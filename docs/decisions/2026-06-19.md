# Decisions — 2026-06-19

## D-2026-06-19-01 — Operator UI displays all times in IST
- **Area:** product
- **Status:** accepted
- **Decision:** Frontend now renders all dates/times and computes the 'today'/weekend day-boundary in Asia/Kolkata (IST), not America/Los_Angeles. Manual 'Start sending' override and the scheduled_timezone default now interpret operator-picked times as IST. The autonomous daily send window (9-11:30 AM PT) remains backend-controlled and unchanged.
- **Why:** Operator is India-based; PT-based day boundary made the Daily run panel show the wrong day (run_date stamped at 8 AM IST vs UI 'today' computed in PT). IST display also fixes that mismatch. US-recipient send window stays backend-enforced.
- **Refs:** frontend/app/lead-gen/page.tsx, frontend/app/actions/page.tsx, frontend/lib/api.ts, frontend/lib/utils.ts

## D-2026-06-19-02 — AI Audit clicks use dedicated signed redirects
- **Area:** lead-gen
- **Status:** accepted
- **Decision:** AI Audit freeware links are generated in code with HMAC-signed contact tokens and routed through `/aiaudit/go`, which writes `audit_link_clicks`, records a deterministic `link_clicked` observation with `channel=ai_audit`, and redirects to the standalone AIAudit app with non-PHI prefill plus `c=<click_id>`. A forced-only `ai-audit` composer variant exists for audit-first outreach, while normal lead-gen email signatures get a small audit link appended by code.
- **Why:** Audit-link attribution has to happen before the questionnaire loads and must tie back to `firm_contacts` / lead-gen observations even when the recipient never completes the survey. Keeping URLs out of LLM output avoids PHI/link-source drift and keeps the composer plaintext.
- **Refs:** app/services/aiaudit_links.py; app/api/aiaudit.py; app/services/lead_email_composer.py; app/skills/possible-minds-lead-email-composer/variants/ai-audit
