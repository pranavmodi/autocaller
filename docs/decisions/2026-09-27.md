# Decisions - 2026-09-27

## D-2026-09-27-01 — Keep Job Agent mailbox access a bounded read-only tool
- **Area:** product
- **Status:** accepted
- **Decision:** Give the website application controller one audited Zoho inbox-search action backed by deterministic IMAP code, rather than a mailbox sub-agent. Limit it to recent, specific queries and transient message content; persist only search metadata.
- **Why:** Form completion sometimes needs employer or ATS mail, but unrestricted mailbox agency would increase privacy and action risk without improving the mechanical lookup.
- **Refs:** `app/services/job_browser_mail.py`, `app/services/job_browser.py`, `docs/JOB_BROWSER_APPLICATIONS.md`

## D-2026-09-27-02 — Permit scoped email-code completion after website submit
- **Area:** product
- **Status:** accepted
- **Decision:** Allow the website application controller to search recent Zoho inbox mail and complete a visible one-time email verification step after initial submission for any employer or ATS. Validate the newest matching message and visible controls, perform one guarded verification sequence with a single final click, and persist only redacted metadata.
- **Why:** Verification emails arrive only after the initial submit. The prior read-only lock made the existing inbox tool unusable at that point and forced the operator to copy codes manually.
- **Refs:** app/services/job_browser.py, app/services/job_browser_tools.py, app/skills/job-browser-agent/SKILL.md

## D-2026-09-27-03 — Search bounded inbox-like folders for application mail
- **Area:** product
- **Status:** accepted
- **Decision:** Search INBOX and Zoho's Notification folder by default for current job-application mail, with an environment-configurable allowlist capped at four folders. Continue excluding Sent, Drafts, Templates, Trash, and Archive.
- **Why:** Zoho classifies automated ATS verification messages into Notification, so an INBOX-only reader misses codes that are visible in the user's mailbox.
- **Refs:** app/services/job_browser_mail.py, app/services/inbound_email.py
