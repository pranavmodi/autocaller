# Decisions — 2026-09-28

## D-2026-09-28-01 — Recover job-board failures onto exact official application pages
- **Area:** product
- **Status:** accepted
- **Decision:** A failed model-audited pre-form navigation triggers a bounded search for the exact role on the employer site or official ATS. The worker verifies employer, role and application evidence, then continues in a fresh browser on that official page.
- **Why:** Aggregator overlays and sign-in walls should not stall an authorized application or be confused with a possible submission, while exact-role verification prevents applying through a generic talent pool or different opening.
- **Refs:** `app/services/job_application_source.py`, `app/services/job_browser.py`

## D-2026-09-28-02 — Use role-specific judgment for subjective application answers
- **Area:** product
- **Status:** accepted
- **Decision:** The website application agent should answer subjective preference and positioning fields using reasonable role-specific judgment, including market-aligned desired compensation, while continuing to ask for unknown legal, identity, credential and other hard facts.
- **Why:** Routine preference questions should not stall an authorized application, but presenting the applicant as viable must remain grounded in verified experience and must never create false biographical or legal claims.
- **Refs:** `app/skills/job-browser-agent/SKILL.md`, `app/skills/possibleos-job-applicant-context/SKILL.md`
