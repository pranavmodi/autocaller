# Decisions — 2026-08-11

## D-2026-08-11-01 — Use channel-neutral daily campaigns for website engagement
- **Area:** data-arch
- **Status:** accepted
- **Decision:** Model daily campaigns separately from channel execution; give each email, LinkedIn, or public touch its own allowlisted Possible Minds tracking link and deduplicate people only at campaign rollup.
- **Why:** This preserves direct-touch attribution, supports anonymous public posts, and avoids forcing LinkedIn activity into the email-only outreach tables.
- **Refs:** engagement_campaigns, engagement_campaign_links, /t/{code}, /click-analytics
