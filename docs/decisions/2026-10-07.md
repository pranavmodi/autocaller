# Decisions - 2026-10-07

## D-2026-10-07-01 - Keep the operations app out of search results
- **Area:** website
- **Status:** accepted
- **Decision:** Serve noindex, nofollow for Possible OS frontend pages on both app hostnames. Allow crawling so Google can see noindex on existing login URL variants. Deploy the header at nginx without rebuilding unrelated frontend WIP; mirror the policy in Next metadata for subsequent builds.
- **Why:** Search Console lists login?next= variants as duplicate pages. They are internal software, not public marketing pages. A crawl-blocking robots rule would prevent Google from observing noindex. Search exclusion is not an access-control mechanism; existing authentication stays unchanged.
- **Refs:** deploy/nginx/autocaller.conf; frontend/app/layout.tsx; frontend/app/robots.ts
