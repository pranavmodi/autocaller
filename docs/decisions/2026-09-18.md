# Decisions — 2026-09-18

## D-2026-09-18-01 — Persist job application checkpoints separately from display text
- **Area:** product
- **Status:** accepted
- **Decision:** Store a machine-readable application phase, attempt number, failure phase, retryability and checkpoint timestamps in the existing processing JSON. Render the job modal from these facts as a seven-step timeline.
- **Why:** A single stage label could not distinguish work already completed from the active or failed operation. Persisted checkpoints give the UI and CLI the same accurate state after polling or process restarts, while keeping uncertain sends on verification-only recovery.
- **Refs:** `app/services/job_agent_processing.py`, `frontend/components/JobApplicationControls.tsx`, `docs/JOB_AGENT.md`
