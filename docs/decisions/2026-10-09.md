# Decisions — 2026-10-09

## Cross-run job discovery ledger

- Show final job findings from every saved-search run in one paginated view.
- Group repeats by canonical URL and canonical candidate ID while retaining one
  provenance tag per search/run with the discovery time, trigger and outcome.
- Derive the ledger from immutable `career_search_runs`; do not create a second
  job store or alter canonical Job Agent deduplication.
- Expose independent search and exact-run filters while keeping all provenance
  tags on a matching job visible.
- Open the cross-run ledger by default in Searches; retain a toggle for saved-search
  configuration and preserve exact-run deep links.
- Treat manual Applied as a separate operator record. Preserve prior draft state for
  undo, block duplicate automation, and never translate it into provider evidence.
