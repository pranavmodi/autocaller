# Decisions — 2026-09-20

## D-2026-09-20-01 — Start Job Agent search as an operator action
- **Area:** product
- **Status:** accepted
- **Decision:** Job Agent external search uses saved role, industry and location preferences, verifies legal-domain employers and live job/geography evidence, deduplicates mechanically, and imports into the review queue without classification or application authority. Manual runs remain distinct from the scheduled PI search.
- **Why:** This delivers observable search and shortlisting first while preventing a search request from consuming a daily slot or implicitly authorizing classification, email, or form submission.
- **Refs:** `app/services/daily_career_search.py`, `app/services/job_agent.py`, `frontend/app/job-agent/page.tsx`
