# Decisions — 2026-06-24

## D-2026-06-24-01 — Forced daily re-run gains --cancel-existing to supersede the prior same-day batch safely
- **Area:** lead-gen
- **Status:** accepted
- **Decision:** Forced daily re-run gains --cancel-existing to supersede the prior same-day batch safely
- **Why:** A force re-run creates a new batch + new scheduled sends but never cancelled the old batch's approved sends -> both would fire = double-email the leads. --cancel-existing cancels the superseded batch's approved/waiting (unsent) sends first. Also set everyday LEAD_GEN_FOLLOW_UP_VARIANT=ai-audit and daily_batch_size=40 (20 Zoho + 20 Resend via transport overflow).
- **Refs:** app/services/lead_gen_daily.py (_cancel_batch_sends), app/api/lead_gen.py, app/cli.py (--cancel-existing)
