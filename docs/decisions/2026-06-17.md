## D-2026-06-17-19 — First-touch lead emails default to the Yelp-pain-quote composer variant
- **Area:** lead-gen
- **Status:** accepted
- **Decision:** All first-touch (non-follow_up) lead-gen emails now compose with the new 'yelp-pain-quote' variant by default. It cites a real extracted Yelp client-communication complaint verbatim+attributed as the hook when one exists, and falls back to a clean baseline email (no review mention) when none is extracted. Follow-up steps keep their sequence/explicit variant. Variant has allocation_weight=0 so it is excluded from the random A/B rendezvous pool and only ever used when explicitly forced. - **Why:** A real, attributed pain quote is a far stronger first-touch hook than inferred firm_behavior signals; weight=0 keeps it out of the subject-line A/B so follow-ups are never randomly assigned the Yelp framing. Never fabricates: fallback path proven to omit Yelp entirely when no quote.
- **Refs:** app/services/lead_email_composer.py review_evidence; app/services/lead_gen_email_agent.py LEAD_GEN_FIRST_TOUCH_VARIANT; variants/yelp-pain-quote/{SKILL.md,variant.json}
