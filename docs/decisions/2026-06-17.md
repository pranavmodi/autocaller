## D-2026-06-17-22 — Automatic Yelp-review extraction (paste -> citable quote)
- **Area:** lead-gen
- **Status:** accepted
- **Decision:** Built a programmatic extractor (app/services/review_extraction.py + app/skills/review-quote-extractor/SKILL.md) that turns operator-pasted raw Yelp reviews into the EXTRACTED v1 block the gate/composer read. Triggers: (a) background on PUT /reviews save (REVIEW_AUTO_EXTRACT, default on), (b) pre-gate safety net in _compose_batch_items via ensure_review_extracted. Idempotent via content_hash. CLI: reviews extract / extract-all-pending; REST POST /api/firms/{pif_id}/extract.
- **Why:** Extraction was previously manual (an agent ran the yelp-review-quotes runbook), so pasted reviews never became citable quotes and first-touch firms stayed blocked. Kept extraction a separate deterministic step (not inside the composer) so the gate has a deterministic signal and quotes stay verbatim/verifiable. Still client_communication-only; v2 (praise/facts/typed evidence) is designed but not built.
- **Refs:** review_extraction.py; review-quote-extractor/SKILL.md; firm_reviews.py PUT trigger + /extract; REVIEW_AUTO_EXTRACT

- **Status:** accepted

Kept gate/composer behavior identical this phase to de-risk; broadening is Phase 3.
