# Decisions — 2026-07-13

## D-2026-07-13-01 — Workshop tracked links get their own /w/ kind instead of per-link dest on /s/
- **Area:** lead-gen
- **Status:** accepted
- **Decision:** Added `kind="workshop"` short links (`/w/<code>`, `build_short_workshop_link`, `WORKSHOP_PAGE_URL` dest env) rather than adding a per-link destination column to `audit_links`. The /w/ redirect appends per-recipient prefill params (contact_name/contact_email/firm_name) by resolving the contact server-side.
- **Why:** Matches the existing one-kind-per-destination pattern (audit/consult/solution/intake), needs no migration, and keeps recipient PII out of email URLs (params are added only at redirect time from the DB, so the mailed link stays a bare short code).
