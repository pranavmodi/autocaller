## D-2026-06-23-01 - Reuse click attribution for AI Visibility report links
- **Area:** lead-gen
- **Status:** accepted
- **Decision:** AI Search Visibility report emails use a dedicated `visibility_links` short-code table for `/v/<code>` report destinations, but continue writing clicks into the existing `audit_link_clicks` table with `source=visibility_report_email`.
- **Why:** The short code needs to resolve a scan report, which `audit_links` cannot express, while the shared click table keeps downstream lead-gen observations and attribution reporting on one proven path.
- **Refs:** app/services/visibility_links.py, app/api/visibility_links.py, app/db/models.py
