## D-2026-09-02-01 — Derive consolidated Lead Finder catalog from publish events

- **Status:** accepted
- **Decision:** Build the cross-run lead catalog from completed lead_finder.add_researched_lead tool calls and preserve run/step provenance; do not aggregate mutable run context.
