## D-2026-06-25-05 — `consult_link_present` send-gate must accept the tracked /c/ link (regression fix)
- **Area:** deliverability
- **Status:** accepted
- **Decision:** The send-time policy check `consult_link_present` in `action_execution.py` matched only the literal `getpossibleminds.com/consult`. After the consult-link tracking feature replaced that with a per-recipient `/c/{code}` link, the check failed and **blocked every lead-gen send for ~1 hour** (all 60 of today's approved sends sat un-sent from 16:01 UTC). Lesson: any send-gate that string-matches email content must be updated in lockstep when the composer changes that content.
- **Why:** The gate exists to guarantee the consult CTA is present; it must recognize the tracked form of that CTA.
- **Refs:** app/services/action_execution.py:1534 (consult_link_present -> _has_consult_link)

## D-2026-06-25-01 — Consult CTA link gets per-recipient click tracking, reusing the audit-link infra

- **Status:** accepted
- **Decision:** The consult CTA in lead-gen emails now uses a per-recipient tracked `/c/{code}` short link (built at compose time, mirroring the audit `/a/{code}` link) instead of the bare `https://getpossibleminds.com/consult` constant. ## D-2026-06-25-02 — Backfill already-scheduled sends by rewriting body + re-approving at the existing slot
- **Area:** lead-gen
- **Status:** accepted
- **Decision:** `lead-gen backfill-consult-links --scope today|all` rewrites unsent lead-gen send bodies (bare consult URL -> tracked `/c` link), recomputes the sanitized subject/body sha256, and re-binds the hash-bound approval block while keeping `scheduled_for` intact. Used to upgrade today's 60 already-approved sends in place (verified: 60/60 tracked, 60/60 approval hash matches sanitized body). Idempotent; rows already carrying `/c/` are skipped.
- **Why:** Approvals are hash-bound so the scheduler sends the exact approved draft; changing a body invalidates the hash, so any in-place edit of an approved send must re-approve. Doing it as a scriptable, idempotent backfill (rather than per-send substitution at execution time) preserves the "send exactly the approved draft" invariant.
- **Refs:** app/services/action_execution.py (backfill_consult_short_links), app/api/lead_gen.py (POST /api/lead-gen/backfill-consult-links), app/cli.py (lead-gen backfill-consult-links)
